# WMI Website Progress

Public, no-sign-in progress page for the World Mission Initiative website rebuild.

Live site: https://firesnatchers316.github.io/wmi-progress/

## Update the page

1. Edit the `STATUS` object at the top of the script in `index.html`.
2. Commit and push to `main`. GitHub Pages will republish automatically.

From this folder, after files are edited:

```bash
# If using the GitHub MCP tools from Grok Bot, update index.html in the
# firesnatchers316/wmi-progress repo on the main branch.
```
